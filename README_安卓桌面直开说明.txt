抱石训练（安卓桌面图标无黑边版）安装说明

已处理：
- 192px、512px 图标的黑色背景全部变成透明。
- 另提供金黄色完整背景的 maskable 图标，适配安卓不同形状的桌面图标。
- 网页中的训练打卡、日历、计时与动作说明均保留。

最稳定的安装方法：
1. 解压 ZIP。
2. 把其中全部文件部署到支持 HTTPS 的静态站点（如 GitHub Pages / Cloudflare Pages）。
3. 用安卓 Chrome 访问网址，菜单 ⋮ → “安装应用” / “添加到主屏幕”。
4. 桌面图标就会用无黑边的面包皇冠图案，点开可直接进入训练网页。
5. 如果以前安装了黑边旧图标，请删除旧的桌面快捷方式，重新添加；如仍未刷新，可在浏览器站点设置中清除对应站点缓存后再安装（先导出打卡记录备份）。

离线使用：
- 首次联网打开并完成 PWA 缓存后，可以离线启动网页和打卡。
- 视频教程、在线补充夸夸需要网络。

单文件 HTML 也可离线打开，但直接用本地文件方式打开时，不保证安卓系统允许安装为桌面 PWA。
